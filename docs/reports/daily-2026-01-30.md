## Decisions Made
None formally logged today. Key design decisions made in conversation:
- Variable picker shows previous steps' outputs (not current step) - this is the correct flow for building step chains
- `[v]` for Variable instead of `[p]` for Pick - better UX
- Inline hints on param fields rather than global hint bar
- Direct insertion on pick rather than two-step pick-then-insert

## Blockers & Issues
- **Nested params**: Complex object-type parameters (like `config` for `data.json_to_markdown`) require users to type raw JSON. Need hub-core to provide `properties` field in ToolParam schema so TUI can render nested form fields.

## Next Steps
1. Hub-core: Add `properties` field to ToolParam for nested object schemas
2. Hub-core: Add `items` field for array type schemas
3. Continue Phase 8: Polish & Edge Cases
4. Better param documentation/examples from API
